# Security policy

Pr0jectZer0 Auth is under active development and is not yet represented as production-supported or generally available.

Do not open a public issue for a suspected vulnerability. Report it privately through GitHub's security-advisory feature for this repository and include the affected version, reproduction steps, and expected impact. Do not include real enrollment secrets, signing keys, device keys, or customer data.

Release artifacts must be signed through the protected Android beta workflow. Debug-signed builds must never be distributed to testers.
